# Real screenshots (optional)

The page draws the app's windows in HTML/CSS. Put a real screenshot here with one of these names and
it replaces the drawing automatically:

| File | Where it appears |
|---|---|
| `archive.png` | Hero: an archive open in the browser view |
| `home.png` | Screenshots › Home |
| `compress.png` | Screenshots › Compress |
| `extract.png` | Screenshots › Extract |

Use a window capture (⌘⇧4, then Space, then click the window; hold ⌥ to drop the shadow). Export at
2× and keep each under about 500 KB, e.g. `sips -Z 1920 archive.png`. Any aspect ratio works.
